Privacy Policy - "hataktzir uploader"

Last updated: September 27, 2026

What this app is

"hataktzir uploader" is a private tool used only by the owner of the YouTube channel Hataktzir (@hataktzir) to upload videos to that channel and to set their thumbnails and visibility. It is not offered to the public, and no other users sign in to it.

What data it accesses

With the channel owner's consent, the app uses the YouTube Data API with these scopes:

  • youtube.upload - to upload videos to the owner's channel;
  • youtube.force-ssl - to set a video's thumbnail and change its privacy status.

It reads basic channel information (channel name and ID) only to confirm it is connected to the correct channel.

How data is stored and shared

The OAuth token is stored only on the owner's own computer. No Google user data is sent to any third party, sold, used for advertising, or used to train AI models. Nothing is collected from viewers of the channel.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used in accordance with the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also ends access.
